# Contributing
Thanks for helping make the archive more honest and useful.

A strong exhibit documents: **the attempt**, **context and assumptions**, **evidence**, **what was learned**, and **what you would try next**. Be generous, specific, and avoid naming or shaming people or sharing private information.

For code contributions: test desktop and mobile, keep the visual language restrained and accessible (including `prefers-reduced-motion`), label interactive controls, and update documentation. Pull requests should explain the change and include screenshots for significant visual updates.
